# Fable 5.2 · 立体幻境展馆

> **在线直接逛：** https://wang-lao-shi.github.io/fable-5.2-awesome-collection/

## 这是什么？（大白话版）

这是一个 **AI 做出来的 3D 网页作品展示馆**。

简单来说，里面收拢了一批用 **Fable 5.2** 等 AI 工具直接“手搓”出来的网页版 3D 游戏、互动场景和动画短片——**不用下载安装包、不用配任何开发环境，点开网页就能直接玩、直接看**。

整个合集主要分两部分：
1. **21 个「离线单文件」精选作品**（带绿色标签）：每个作品都被打包成了单独的一个 `.html` 文件（从几十 KB 到二十多 MB 不等），**就算断网，在电脑上双击也能直接打开玩**。
2. **170+ 个全网热门在线作品直达**：整理了全网最火的一批 AI 3D 网页演示链接，点一下就能跳转体验。

## 怎么用？

### 方式一：直接在线看（最省事）
直接点击访问：https://wang-lao-shi.github.io/fable-5.2-awesome-collection/

### 方式二：下载到本地离线玩
1. 下载本仓库（点击右上角 `Code` → `Download ZIP` 并解压）。
2. 双击打开根目录下的 `index.html`（或 `导航.html`），就能像逛展馆一样点开所有作品。
3. 也可以直接进 `singles/` 文件夹，双击任意一个 `.html` 文件单独运行。

---

## 目录说明

- `index.html` / `导航.html`：总展馆导航页，所有作品的入口。
- `singles/`：21 个已经打包好的单文件 3D 作品（`.html`）。
- `prompts/` & `提示词.txt`：部分作品复刻或生成时用到的提示词参考。
- `作品链接清单.txt`：合集作品的链接整理清单。
